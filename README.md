# プリコネ目押しトレーナー

YouTube動画を見ながら目押しのクリック位置を練習し、指定フレームとの差を記録するブラウザ完結型の練習ツールです。

## できること

- YouTube URLを指定して公式埋め込みプレーヤーで再生
- 目標FPSと目標フレームを指定し、クリック時のフレームと差分を記録
- TL/概要欄を右ペインに表示し、行に目標フレームを設定
- 行クリックで対象フレームへジャンプ、前後5秒/2秒の練習区間を再生
- 再生・逆方向・速度変更・1フレーム送り/戻し・音量・ミュート・ビープ音
- フレーム進行インジケータとログ表示
- 設定・TL行・練習ログのJSONインポート/エクスポート
- キーボード操作（Space、J/K/L、矢印、Enter、M、B）

## 起動

ビルド不要の静的サイトです。ローカル確認は次のいずれかで行えます。

```sh
python3 -m http.server 8000
```

ブラウザで <http://localhost:8000/> を開きます。`file://` 直開きではYouTube IFrame APIやモジュール制約の影響があるため、HTTP経由で開いてください。

## 公開

GitHub Pages / Google Sitesから静的ファイルを公開できます。Google Sitesへは、このアプリをGitHub Pages等に公開したURLを埋め込む方法を想定しています。サーバーやAPIキーは不要です。

YouTubeの公式プレーヤーを利用し、YouTubeのUIやブランドをコピーしません。動画の再生・広告・利用条件はYouTube側に従います。

## データとプライバシー

- 入力したURL、TL、ログはブラウザ内のメモリだけで扱い、外部サーバーへ送信しません。
- 自動保存は行いません。必要な場合だけJSONをエクスポートしてください。
- エクスポートJSONには動画URL、TL、練習ログが含まれるため、共有時は内容を確認してください。

# 目押しトレーナー設計

## 目的

プリンセスコネクトのバトル動画を対象に、動画上の操作タイミングをフレーム単位で反復練習する。ゲームの自動操作や動画のダウンロードは行わず、ユーザーのクリック時刻を計測する。

## 構成

- `index.html`: セマンティックな画面構造、入力欄、操作ボタン
- `styles.css`: YouTubeに依存しないダークな動画ツールUI
- `app.js`: YouTube IFrame API、状態管理、描画、JSON入出力、キーボード操作
- 静的ホスティングのみ。バックエンド、Cookie、localStorage、APIキーは使用しない

## フレーム計算

`frame = round(currentTime * fps)` とする。目標との差は `actual - target` で、負数は早め、正数は遅めを意味する。YouTube IFrame APIが返す時刻は動画の実時間であり、埋め込みプレーヤーの都合で厳密な映像フレーム取得を保証するものではないため、画面には「推定フレーム」と表示する。

目標フレーム `F` の練習区間は `(F - 5 * fps) / fps` から `(F + 2 * fps) / fps`。開始時刻へ移動して再生し、終了時刻に到達したら目標前のループ開始位置へ戻る。YouTube APIのキーフレームシーク特性により、シーク位置は近傍から始まる場合がある。

## データ形式

```json
{
  "version": 1,
  "video": { "url": "https://www.youtube.com/watch?v=...", "fps": 60 },
  "notes": "概要欄やメモ",
  "rows": [{ "id": "row-1", "label": "1:00 ユカリUB", "frame": 3600 }],
  "logs": [{ "id": "...", "rowId": "row-1", "targetFrame": 3600, "actualFrame": 3598, "delta": -2, "createdAt": "..." }]
}
```

## キーボード

| キー | 操作 |
|---|---|
| Space / K | 再生・一時停止 |
| J / ← | 1フレーム戻し |
| L / → | 1フレーム送り |
| Shift+J / Shift+L | 逆方向/順方向の低速再生 |
| Enter | 目押しクリックを記録 |
| M | ミュート切替 |
| B | 1秒電子音のON/OFF |

## 制約と安全策

- YouTube埋め込みが禁止された動画は再生できない。
- 逆再生はYouTube IFrame APIにないため、APIの再生速度を負数にせず、低速再生とフレーム戻しで代替する。
- 動画FPSは自動判定せず、ユーザーが指定する。60fps/30fps/59.94fps等に対応する。
- YouTubeのブランド表示を隠すパラメータは使用しない。

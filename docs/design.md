# 目押しトレーナー設計

## 目的

プリンセスコネクトのバトル動画を対象に、動画上の操作タイミングをフレーム単位で反復練習する。ゲームの自動操作や動画のダウンロードは行わず、ユーザーのクリック時刻を計測する。

## 構成

- `index.html`: セマンティックな画面構造、入力欄、操作ボタン
- `styles.css`: YouTubeに依存しないダークな動画ツールUI
- `app.js`: YouTube IFrame API、状態管理、描画、JSON入出力、キーボード操作
- 静的ホスティングのみ。バックエンド、Cookie、localStorage、APIキーは使用しない
- YouTube IFrame APIの `origin` はHTTP/HTTPSのホストページでのみ `location.origin` を設定する。`file://` 直開きはエラー153回避のため動画読み込み前に案内して停止する。

## 開発・運用ポリシー

### 費用

- 静的ファイルと無料枠のホスティングだけで動くことを優先する。
- 有料サーバー、従量課金API、広告、決済、独自バックエンドを追加しない。
- 無料サービスの仕様変更・終了時に自動で課金へ移行しない。必要なら別の無料静的ホスティングへ移行する。

### 適法性・規約

- YouTube公式IFrame Player APIと公式埋め込みプレーヤーを利用する。YouTubeのUIやブランドを模倣せず、ブランド表示を隠さない。
- 動画の取得・保存・再配布、DRM・広告・地域制限の回避、非公式APIや自動スクレイピングを実装しない。
- YouTube動画、ゲーム映像、音声、画像、TL、概要欄などの権利はそれぞれの権利者に帰属する。MIT Licenseの対象はこのリポジトリのコードとドキュメントだけである。
- 権利者の許諾やサービス規約上の根拠が確認できないデータは、サンプル・テスト・公開成果物に含めない。
- 法律・規約上の判断が必要な機能は、判断できるまで実装・公開を保留する。ここに記載する方針は法的助言ではない。

## フレーム計算

`frame = round(currentTime * fps)` とする。目標との差は `actual - target` で、負数は早め、正数は遅めを意味する。YouTube IFrame APIが返す時刻は動画の実時間であり、埋め込みプレーヤーの都合で厳密な映像フレーム取得を保証するものではないため、画面には「推定フレーム」と表示する。

目標フレーム `F` の練習区間は `(F - 5 * fps) / fps` から `(F + 2 * fps) / fps`。開始時刻へ移動して再生し、終了時刻に到達したら目標前のループ開始位置へ戻る。YouTube APIのキーフレームシーク特性により、シーク位置は近傍から始まる場合がある。

右ペインの「TLを行化」は、空行を除く各行を目標行にする。行内に `分:秒` があれば秒をFPSへ変換し、`123f` があればその値を目標フレームにする。それ以外の行はラベルだけを作り、フレームは手入力とする。既存行へ追加する動作であり、概要欄テキスト自体は変更しない。

練習中は目標の2秒後を終了境界とする。通常の時間監視に加え、YouTubeの終了イベントでも開始位置へシークして再生を再開するため、動画の終端が近い目標でもループする。

## データ形式

```json
{
  "version": 1,
  "video": { "url": "https://www.youtube.com/watch?v=...", "fps": 60 },
  "notes": "概要欄やメモ",
  "rows": [{ "id": "row-1", "label": "1:00 ユカリUB", "frame": 3600 }],
  "logs": [{ "id": "...", "rowId": "row-1", "targetFrame": 3600, "actualFrame": 3598, "delta": -2, "createdAt": "..." }]
}
```

## キーボード

| キー | 操作 |
|---|---|
| Space / K | 再生・一時停止 |
| J / ← | 1フレーム戻し |
| L / → | 1フレーム送り |
| Shift+J / Shift+L | 逆方向/順方向の低速再生 |
| Enter | 目押しクリックを記録 |
| M | ミュート切替 |
| B | 1秒電子音のON/OFF |

## 制約と安全策

- YouTube埋め込みが禁止された動画は再生できない。
- 逆再生はYouTube IFrame APIにないため、APIの再生速度を負数にせず、低速再生とフレーム戻しで代替する。
- 動画FPSは自動判定せず、ユーザーが指定する。60fps/30fps/59.94fps等に対応する。
- YouTubeのブランド表示を隠すパラメータは使用しない。
